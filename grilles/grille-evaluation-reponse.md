# Grille d'évaluation d'une réponse

Cinq critères, chacun noté de 0 à 2 ; total sur 10. À appliquer à chaque résultat important, et dans l'atelier 4.

| Critère | La question à se poser | Le test rapide | 0 – 2 |
|---|---|---|---|
| **Pertinence** | Répond-elle à la question posée, pour le bon public, dans le bon format ? | Lire la demande, puis la réponse : écart ? | |
| **Exactitude** | Les faits, chiffres, dates, noms et citations sont-ils vrais ? | Vérifier 2 faits au hasard dans une source fiable | |
| **Complétude** | Manque-t-il un point clé, une exception, un cas limite ? | Demander : « qu'as-tu omis ? » | |
| **Cohérence** | La réponse se contredit-elle ? Le raisonnement tient-il ? | Reposer la question autrement : même réponse ? | |
| **Sources** | Les références existent-elles et disent-elles bien cela ? | Ouvrir chaque lien ; tester une citation | |
| **Total /10** | | | |

| Score | Décision |
|---|---|
| **8 – 10** | Utilisable après relecture |
| **5 – 7** | Itérer : préciser le prompt, exiger les sources, découper |
| **< 5** | Repartir de zéro, ou faire soi-même |

Le réflexe : plus la réponse est fluide et assurée, plus elle mérite d'être vérifiée. **L'aisance n'est pas une
preuve.**

## Signaux d'alerte

- Chiffres très précis sans source (« 73,4 % des entreprises… »)
- Références, lois, articles, URL impossibles à retrouver
- Citations attribuées à des personnalités, trop parfaites
- Réponse identique quelle que soit la nuance de la question
- Stéréotypes : métiers genrés, prénoms « typiques », cultures caricaturées
- Dates ou versions récentes présentées avec assurance
- Ton péremptoire : « il est bien connu que… »
- Accord systématique avec vous (flagornerie)

## Techniques de détection

| Technique | Comment |
|---|---|
| **Exiger les sources** | « Cite tes sources avec URL ; si tu n'es pas sûr, dis-le. » |
| **Recouper** | Vérifier 2 faits clés dans une source indépendante |
| **Reformuler** | Poser la même question autrement, ou à une autre IA |
| **Auto-critique** | « Relis ta réponse et liste ce qui pourrait être faux. » |
| **Tester les biais** | Changer le prénom, le genre, le pays : la réponse change-t-elle ? |
| **Fixer le périmètre** | « Réponds uniquement à partir du document joint. » |
