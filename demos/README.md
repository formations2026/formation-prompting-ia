# Démonstrations commentées

Les démonstrations texte ci-dessous reproduisent des **sorties réelles** d'un modèle de langage, obtenues avec
exactement les prompts indiqués et sans retouche. Rejouez-les dans votre outil : la formulation sera différente,
c'est l'un des enseignements de la journée (variabilité). Ce qui doit rester, c'est l'effet du prompt.
