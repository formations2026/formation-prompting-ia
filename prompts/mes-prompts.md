# Mes prompts

Gabarit pour vos propres prompts et pour démarrer la bibliothèque de votre équipe. Une entrée par prompt ; copiez le
bloc autant de fois que nécessaire. Datez chaque entrée : les outils évoluent, un prompt se rejoue.

Règles de la bibliothèque d'équipe :

- un prompt validé = testé sur un cas réel, note ≥ 8/10 avec la grille d'évaluation ;
- aucune donnée personnelle ou confidentielle dans les exemples ;
- une modification = une nouvelle version datée, l'ancienne reste consultable.
